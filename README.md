# 과학 암기장

식물과 에너지 · 동물과 에너지 학습용 정적 사이트.

- 짧은 암기 카드와 화살표 중심 노트
- 처음 공부하는 집중요약본 12단원: 개념 설명·비교표·모식도
- 이해한 단원과 다시 볼 단원 저장, 관련 암기 카드 연결, 전체 요약본 인쇄
- 외웠어 / 헷갈려 / 모르겠어 평가
- 두 회차 연속 기억한 카드는 오늘 완료
- 다음 날부터 복습 간격 1·3·7·14·30일
- 회차별 시험 6회: 회당 5지선다 15문항 + 단답형 5문항, 총 120문항
- 답안 자동 저장, 문항 이동, 전체 제출 후 일괄 채점
- 첫 시험 점수와 이후 응시 결과를 각각 보관
- 오답·미응답·헷갈려서 맞힌 문항을 개념별 복습 목록에 저장
- 오답 아래 즉시 재시험 없음: 다음 날부터 다른 문항으로 복습
- 서로 다른 날·다른 문항에서 정답 확인 2회 후 기억 확인 완료
- 첫 복습 성공 후 3일 간격, 틀리거나 헷갈리면 다음 날부터 다시 확인
- 해설·관련 개념을 읽는 것은 기억 확인으로 처리하지 않음
- 기존 80문항 자가 채점 기록과 암기·집중요약본 진도는 유지
- 브라우저 내부 저장, 기록 내보내기·불러오기

원본 교재 사진, 손글씨, 원본 PDF, 개인정보는 포함하지 않습니다.
문제와 설명은 제공 자료의 개념을 바탕으로 다시 작성했고, 그림은 직접 그린 모식도입니다.
원자료의 채점 표시 52묶음과 판독 보완 1묶음을 연결합니다. 실제 시험 범위 전체나 공식 정답집을 뜻하지 않습니다.

시험과 복습의 단답형은 제시된 핵심 용어 및 허용된 동의어로 자동 채점합니다. 긴 서술형 답안을 판단하는 인공지능 채점은 사용하지 않습니다. 날짜는 이용 기기의 현지 날짜를 사용합니다.
