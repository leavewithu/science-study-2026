# 과학 암기장

식물과 에너지 · 동물과 에너지 학습용 정적 사이트.

- 암기카드 193장: 5과 58장 + 6과 135장, 짧은 답과 화살표 중심 노트
- 오답뿐 아니라 업로드된 개념 자료와 집중요약본의 기본 암기 내용 포함, 기본 개념 59장 추가
- 기존 134장 앞면 전수 검토: 제목형 문구를 구체적인 질문으로 변경하고 실험 조건·그림 보완
- 앞면: 필요한 조건과 질문 / 뒷면: 핵심 답과 기억 단서
- 핵심 노트의 답 가리기에서도 조건·필수 그림 유지, 정답 그림은 답과 함께 표시
- 꼭 해야 하는 것: 암기 70장(5과 28장 + 6과 42장), 기존 시험 1·2회 40문항
- 추가로 하면 좋은 것: 암기 123장, 기존 시험 3~6회 80문항과 6과 보강 2회 40문항
- 처음에는 필수 범위를 선택. 카드·노트·시험의 우선순위 선택을 공유하고 저장
- 선정 기준: 개념의 뼈대, 자주 혼동하는 구별, 필수 시험의 선행 개념. 출제 예측이나 시험 범위 축소가 아님
- 필수 시험 40문항 각각의 선행 암기카드 연결을 검증. 추가 자료와 전체 오답은 삭제하지 않음
- 필수 암기를 마친 뒤 필수 1·2회로 확인하고, 새로 틀린 내용은 오답 복습에 유지
- 각 범위에 기본 개념과 오답 연결 카드를 함께 포함하며 오답 여부만으로 우선 배정하지 않음
- 전체 단원 암기는 기본 4:6 배정: 20장일 때 5과 8장 + 6과 12장
- 선택한 범위의 남은 카드가 부족하면 다른 과의 카드로 채움. 모두 선택은 빠짐없이 포함
- 5과만 / 6과만 / 세부 단원 선택 가능, 기존 진행 중인 묶음은 유지
- 처음 공부하는 집중요약본 12단원: 개념 설명·비교표·모식도
- 이해한 단원과 다시 볼 단원 저장, 관련 암기 카드 연결, 전체 요약본 인쇄
- 외웠어 / 헷갈려 / 모르겠어 평가
- 두 회차 연속 기억한 카드는 오늘 완료
- 다음 날부터 복습 간격 1·3·7·14·30일
- 공통 시험 6회: 매회 5과 8문항 + 6과 12문항 (4:6), 총 120문항
- 6과 추가 시험 2회: 매회 6과 20문항, 총 40문항
- 총 160문항, 모든 회차는 5지선다 15문항 + 단답형 5문항
- 원자료 오답 53묶음 모두 필수+추가 전체 공통 시험과 암기카드에 연결, 연결표에 우선순위 표시
- 답안 자동 저장, 문항 이동, 전체 제출 후 일괄 채점
- 첫 시험 점수와 이후 응시 결과를 각각 보관
- 오답·미응답·헷갈려서 맞힌 문항을 개념별 복습 목록에 저장
- 오답 아래 즉시 재시험 없음: 다음 날부터 다른 문항으로 복습
- 서로 다른 날·다른 문항에서 정답 확인 2회 후 기억 확인 완료
- 첫 복습 성공 후 3일 간격, 틀리거나 헷갈리면 다음 날부터 다시 확인
- 해설·관련 개념을 읽는 것은 기억 확인으로 처리하지 않음
- 기존 80문항 자가 채점 기록과 암기·집중요약본 진도는 유지
- 이전 2:8 구성의 시험 기록과 진행 중인 답안은 별도로 보관, 그대로 이어 풀기 가능
- 브라우저 내부 저장, 기록 내보내기·불러오기

원본 교재 사진, 손글씨, 원본 PDF, 개인정보는 포함하지 않습니다.
문제와 설명은 제공 자료의 개념을 바탕으로 다시 작성했고, 그림은 직접 그린 모식도입니다.
원자료의 채점 표시 52묶음과 판독 보완 1묶음을 연결합니다. 실제 시험 범위 전체나 공식 정답집을 뜻하지 않습니다.
쪽수가 누락되거나 일부가 잘린 사진의 보이지 않는 내용은 포함 여부를 확인할 수 없습니다.

시험과 복습의 단답형은 제시된 핵심 용어 및 허용된 동의어로 자동 채점합니다. 긴 서술형 답안을 판단하는 인공지능 채점은 사용하지 않습니다. 날짜는 이용 기기의 현지 날짜를 사용합니다.
